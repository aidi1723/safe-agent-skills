# ICBU Listing Workflow

## When To Use

Use this skill when preparing product listing structure for Alibaba
International Station, especially building-material or B2B catalog workflows.

## Safe Workflow

1. Identify product category, buyer persona, SKU depth, target market, and inquiry goal.
2. Collect product facts from user-provided materials before drafting claims.
3. Structure title, attributes, SKU options, selling points, application scenes, and FAQ.
4. Keep compliance-sensitive claims sourced or conservative.
5. Avoid platform-sensitive actions such as account changes, paid promotion, or publishing without approval.
6. Mark missing product data as required input instead of inventing it.

## Expected Output

- listing structure
- attribute checklist
- keyword plan
- inquiry-oriented copy blocks
- missing-input list

## Verifier Expectations

- category rule check
- attribute completeness check
- forbidden-word or unsupported-claim check
- image and asset checklist

## Failure Handling

If product facts are missing, return a required-input checklist before drafting
final listing text.
