# Office Claude Skills Document Review

## When To Use

Use this skill when a backlog candidate concerns Markdown, HTML, document
writing, slide generation, review helpers, report structure, source integrity,
or office-format conversion.

## Safe Workflow

1. Identify source files, target format, reader, layout constraints,
   source-of-truth references, and output artifact.
2. Separate content structure, formatting, conversion, visual check, and link
   or citation integrity.
3. Prefer existing office, data conversion, PDF, DOCX, and source-check skills
   unless the candidate adds a distinct document workflow.
4. Define renderer or parser verification when layout, slides, tables, links,
   or citations matter.
5. Keep file writes scoped to the approved workspace and record generated
   artifacts.

## Expected Output

- document scope and artifact contract
- source and link integrity checklist
- formatting or rendering verification plan
- trusted-skill coverage map
- adoption decision and skipped assumptions

## Verifier Expectations

- source-reference check
- renderer or parser check when applicable
- workspace output check
- candidate-map coverage check

## Failure Handling

If the source files, output format, or rendering tool are unavailable, produce
a structure plan and mark visual/layout verification as blocked.
