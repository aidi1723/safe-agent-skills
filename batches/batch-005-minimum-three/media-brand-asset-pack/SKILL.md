# Media Brand Asset Pack

## When To Use

Use this skill when brand or product media files need organization, review, or
handoff notes.

## Safe Workflow

1. Identify asset types, owner, intended use, and allowed channels.
2. Check naming, dimensions, formats, variants, and usage restrictions.
3. Separate source assets from generated or edited assets.
4. Record missing files and rights uncertainties.
5. Produce a compact handoff inventory.

## Expected Output

- asset inventory
- usage and rights notes
- missing item list
- handoff checklist

## Verifier Expectations

- file existence check
- format and dimension check when available
- rights note check
- duplicate or stale asset check

## Failure Handling

If ownership or usage rights are unclear, mark the asset as review-required.
