# Media Video Script Review

## When To Use

Use this skill when preparing or reviewing a video script, narration, storyboard,
or demo outline.

## Safe Workflow

1. Identify audience, video length, platform, product facts, and required scenes.
2. Check hook, sequence, narration, visual coverage, and claim support.
3. Keep product and brand claims grounded in provided material.
4. Flag missing visuals, rights concerns, or unclear calls to action.
5. Produce a concise script or edit checklist.

## Expected Output

- script review notes
- revised scene outline
- claim and rights warnings
- production checklist

## Verifier Expectations

- source fact check
- scene coverage check
- rights and usage check
- platform fit check

## Failure Handling

If source media is unavailable, write a shot requirement list instead of
inventing visual details.
