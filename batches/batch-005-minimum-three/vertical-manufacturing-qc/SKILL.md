# Vertical Manufacturing QC

## When To Use

Use this skill when a manufacturing workflow needs quality-control structure,
inspection notes, or defect summary preparation.

## Safe Workflow

1. Identify product, batch, specification, inspection method, and acceptance rule.
2. Record defects with location, severity, count, evidence, and disposition.
3. Separate measured facts from suspected root causes.
4. Flag missing samples, unclear standards, and rework decisions.
5. Produce a handoff summary for owner review.

## Expected Output

- QC checklist
- defect table
- acceptance status
- rework or escalation notes

## Verifier Expectations

- specification check
- sample and count check
- evidence attachment check when available
- acceptance rule check

## Failure Handling

If acceptance criteria are missing, provide an inspection template and mark the
decision as pending.
