# Research Source Check

## When To Use

Use this skill when a task needs current facts, source attribution, comparison
between sources, or verification of a claim before it is used in an answer.

## Safe Workflow

1. Identify the exact claim or question to verify.
2. Prefer primary sources, official documentation, standards, papers, filings, or direct data.
3. Record source URL, publisher, date, and why the source is relevant.
4. Compare multiple sources when the claim is time-sensitive, disputed, or high-impact.
5. Separate sourced facts from inference.
6. Report uncertainty and freshness limits explicitly.

## Expected Output

- claim-by-claim verification
- concise source list
- dates and publisher names
- clear distinction between source facts and analysis

## Verifier Expectations

- citation check
- source freshness check
- source type check
- claim-to-source mapping

## Failure Handling

If a claim cannot be verified from reliable sources, state that it is
unverified instead of filling the gap.
