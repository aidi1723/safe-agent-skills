# Research Competitor Brief

## When To Use

Use this skill when a user needs a structured comparison of companies,
products, or public offerings.

## Safe Workflow

1. Define the comparison set, market, date, and decision question.
2. Use current public sources when facts may have changed.
3. Separate verified facts, inferred positioning, and opinion.
4. Compare the same dimensions across every subject.
5. Include source links and capture dates.

## Expected Output

- comparison table
- source-backed observations
- gaps and uncertainties
- decision-relevant summary

## Verifier Expectations

- source recency check
- primary-source preference
- comparable dimensions
- date and link record

## Failure Handling

If sources conflict, preserve both claims and explain which source is stronger.
