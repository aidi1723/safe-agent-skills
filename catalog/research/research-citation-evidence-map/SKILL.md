# Research Citation Evidence Map

## When To Use

Use this skill when a research brief, report, knowledge-base entry, or sourced
summary needs clear claim-to-evidence traceability.

## Safe Workflow

1. Extract key claims, named entities, dates, numbers, comparisons, and causal
   statements from the draft.
2. Map each claim to a source, section, page, table, URL, or local artifact
   reference when available.
3. Separate direct source evidence, paraphrase, synthesis across sources, and
   unsupported inference.
4. Flag claims with missing evidence, weak source type, stale publication date,
   or citation that does not support the sentence.
5. Preserve uncertainty notes and avoid upgrading weak evidence into certain
   language.

## Expected Output

- claim-to-evidence table
- unsupported claim list
- weak or stale source warnings
- direct fact versus inference labels
- citation gap recommendations

## Verifier Expectations

- claim extraction check
- source location check
- evidence support check
- uncertainty label check

## Failure Handling

If sources are unavailable, mark the output as unsourced review and do not
present unsupported claims as verified facts.
