# Data Visualization Plan

## When To Use

Use this skill when data needs to be turned into charts, dashboard sections, or
an explainable visual story.

## Safe Workflow

1. Identify audience, decision question, metrics, dimensions, and data limits.
2. Choose chart types that match the data relationship.
3. Avoid visual encodings that exaggerate or hide uncertainty.
4. Define labels, units, filters, and comparison baselines.
5. Verify that the visual plan answers the original question.

## Expected Output

- chart recommendations
- metric definitions
- layout plan
- caveats and uncertainty notes

## Verifier Expectations

- metric definition check
- axis and unit check
- chart suitability check
- accessibility and readability check

## Failure Handling

If the data is not available, produce a chart plan with required fields and
validation questions.
