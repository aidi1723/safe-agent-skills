# Commerce Product Keyword Plan

## When To Use

Use this skill when a product listing needs keyword structure for search,
category matching, or marketplace discovery.

## Safe Workflow

1. Identify product type, buyer segment, market, attributes, and forbidden claims.
2. Group keywords by category, material, use case, specification, and problem.
3. Separate core terms, long-tail terms, and terms needing evidence.
4. Avoid misleading claims or unsupported certifications.
5. Map keywords to title, bullets, description, and backend fields when needed.

## Expected Output

- keyword groups
- title and bullet targets
- unsupported claim warnings
- listing field mapping

## Verifier Expectations

- product fact check
- category fit check
- unsupported claim check
- duplicated or irrelevant keyword check

## Failure Handling

If product details are insufficient, produce a keyword question list first.
