# Commerce RFP Response Review

## When To Use

Use this skill when preparing or reviewing a proposal response for a buyer,
public tender, enterprise procurement process, or structured questionnaire.

## Safe Workflow

1. Extract mandatory requirements, submission rules, deadline, scoring criteria,
   and disqualifiers.
2. Build a compliance matrix that maps each requirement to a response owner,
   evidence source, and response status.
3. Separate factual capability claims from positioning language.
4. Flag missing attachments, unsupported claims, pricing assumptions, and legal
   or security terms needing specialist review.
5. Produce an answer plan that preserves buyer wording and avoids inventing
   certifications, references, or commitments.

## Expected Output

- requirement compliance matrix
- response gaps and owner list
- evidence and attachment checklist
- claim risk notes
- submission readiness summary

## Verifier Expectations

- mandatory requirement coverage check
- unsupported claim check
- deadline and format check
- legal and security escalation check

## Failure Handling

If the RFP package is incomplete, draft a response-readiness report and mark all
assumptions that require buyer or stakeholder confirmation.
