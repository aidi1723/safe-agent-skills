# Content Social Post

## When To Use

Use this skill when a message must be adapted into short public or internal
channel copy.

## Safe Workflow

1. Identify platform, audience, announcement goal, and factual source.
2. Keep claims specific, verifiable, and aligned with the source.
3. Produce concise variants with different tones only when useful.
4. Avoid promising unavailable features or outcomes.
5. Include a review note for sensitive or regulated topics.

## Expected Output

- post variants
- source fact notes
- channel fit notes
- risk warnings when relevant

## Verifier Expectations

- factual source check
- length and channel check
- sensitive topic check
- link or call-to-action check

## Failure Handling

If source facts are missing, draft only a placeholder structure and request the
missing facts.
