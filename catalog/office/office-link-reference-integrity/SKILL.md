# Office Link Reference Integrity

## When To Use

Use this skill when documents, Markdown pages, reports, or knowledge-base
entries depend on links, anchors, footnotes, cross-references, or bibliography
entries.

## Safe Workflow

1. Inventory internal links, external links, anchors, footnotes, image
   references, bibliography items, and cross-document references.
2. Check that link text accurately describes the destination and does not hide
   a mismatch between claim and source.
3. Verify internal anchors, relative paths, heading references, table references,
   figure references, and duplicate footnote identifiers.
4. Separate mechanical link integrity from source quality and factual support.
5. Record unavailable destinations, missing references, ambiguous anchors, and
   references that require manual review.

## Expected Output

- reference inventory
- broken or ambiguous link list
- anchor and footnote issues
- source support caveats
- repair recommendations

## Verifier Expectations

- link inventory check
- anchor and path check
- footnote identifier check
- link text consistency check

## Failure Handling

If a link destination cannot be checked locally, mark the status as unverified
instead of assuming the reference is valid.
