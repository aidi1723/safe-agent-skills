# PDF Evidence And Rendering Guide

Use this guide when text extraction alone cannot establish document fidelity.

## Input Record

Record the approved file, identity or checksum, size, page count, metadata,
encryption state, and whether pages contain text, images, forms, annotations,
or signatures. Preserve the original artifact.

## Extraction And OCR

Extract text and metadata first. Compare parsed page count and representative
text with rendered pages. Use OCR only on image-only or incomplete pages and
record OCR language, affected pages, and recognition uncertainty.

## Visual Evidence

Render pages when reviewing columns, tables, diagrams, forms, signatures,
headers/footers, clipping, or page order. Reconcile table cells and reading
order with the visible page. Cite page numbers for material statements.

## Output Verification

For a generated or modified PDF, reopen it, confirm page count and extracted
text, render representative and complex pages, and record unreadable content,
layout drift, missing assets, or unresolved fidelity risk.
