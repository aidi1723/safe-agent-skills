# Execution Claude Skills Productivity Review

## When To Use

Use this skill when a backlog candidate describes inbox setup, capture,
triage, reflection, critique, operating cadence, or personal productivity
templates that need bounded agent execution guidance.

## Safe Workflow

1. Identify whether the task is personal organization, team workflow, inbox
   triage, retrospective, critique, or lightweight execution planning.
2. Define allowed data, privacy boundary, stop conditions, and whether account
   or message access is involved.
3. Convert style-heavy prompts into bounded checklists, triage tables,
   action logs, or retrospective templates.
4. Keep account-sensitive actions, message sending, deletion, payment, or
   external publication outside the skill without separate approval.
5. Prefer existing execution, office, business, or browser-boundary skills
   when a candidate overlaps normal task handling.

## Expected Output

- task-intake and privacy boundary
- triage or action-log format
- owner, next action, and stop-condition notes
- trusted-skill coverage map
- adoption decision and approval needs

## Verifier Expectations

- private-data boundary check
- account-sensitive action check
- duplicate execution-skill check
- candidate-map coverage check

## Failure Handling

If a productivity workflow requires private account access, produce a read-only
plan and request explicit host approval before any sensitive action.
