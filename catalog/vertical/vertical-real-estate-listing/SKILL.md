# Vertical Real Estate Listing

## When To Use

Use this skill when drafting or reviewing property listing text, feature
summaries, or buyer-facing property notes.

## Safe Workflow

1. Identify property type, location, verified facts, photos, and listing channel.
2. Separate confirmed features from owner claims and assumptions.
3. Avoid unsupported legal, financial, school, zoning, or return claims.
4. Structure copy around location, layout, condition, amenities, and next steps.
5. Mark missing facts and required owner review.

## Expected Output

- listing draft
- verified fact table
- unsupported claim warnings
- owner review questions

## Verifier Expectations

- property fact check
- channel fit check
- sensitive claim check
- photo or asset reference check when available

## Failure Handling

If property facts are incomplete, write a safe draft skeleton and request the
missing details.
