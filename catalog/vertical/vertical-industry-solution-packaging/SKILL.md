# Vertical Industry Solution Packaging

## When To Use

Use this skill when turning industry intake, compliance boundaries, domain
evidence, and selected trusted skills into a reusable customer-facing solution
plan or delivery package.

## Safe Workflow

1. Define the target users, industry segments, use cases, non-goals, data
   inputs, outputs, operating cadence, and success metrics.
2. Map the solution into reusable modules: intake, domain evidence, data
   quality, privacy and compliance, workflow execution, content or report
   generation, verification, and handoff.
3. Bind each module to trusted skills or mark the gap explicitly. Avoid loading
   broad persona skills when a narrower trusted workflow covers the need.
4. Create a staged delivery plan with acceptance criteria, review gates,
   required evidence, owner responsibilities, and rollback or escalation steps.
5. Include industry-specific copy only when evidence and approval boundaries
   are recorded.

## Expected Output

- industry solution blueprint
- reusable module map
- selected skill and bundle routing table
- acceptance criteria and verification gates
- delivery risks and next-step backlog

## Verifier Expectations

- module-to-skill coverage check
- acceptance criteria check
- regulated boundary check
- evidence and owner handoff check

## Failure Handling

If a module lacks a trusted skill, mark it as a capability gap and keep the
solution package in draft until a trusted local skill or approved process exists.
