# Education Planning Workflow

## When To Use

Use this skill when a task involves lesson planning, study workflow design,
learning objectives, practice activities, or educational content structure.

## Safe Workflow

1. Identify learner age, level, language, subject, goals, and constraints.
2. Define measurable learning objectives before content.
3. Structure instruction into explanation, example, practice, feedback, and review.
4. Avoid high-stakes educational claims without evidence or teacher review.
5. Adapt tone and difficulty to the learner context.
6. Include assessment or reflection steps when useful.

## Expected Output

- learner context summary
- learning objectives
- lesson or study plan
- practice tasks
- assessment or review notes

## Verifier Expectations

- domain checklist
- safety escalation check for minors or sensitive topics
- source citation check when factual claims are specialized

## Failure Handling

If learner context is missing, provide a conservative draft and list the missing
information needed to tailor it.
