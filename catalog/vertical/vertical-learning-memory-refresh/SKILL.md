# Vertical Learning Memory Refresh

## When To Use

Use this skill when a learning plan, knowledge-base workflow, or long-running
agent memory process needs scheduled review to prevent knowledge decay.

## Safe Workflow

1. Identify the learner or agent context, knowledge units, source quality,
   deadline, and acceptable review load.
2. Split material into reviewable units with source references and priority
   levels.
3. Assign refresh intervals based on difficulty, recency, error history, and
   business importance rather than arbitrary repetition.
4. Include lightweight recall checks before re-reading or re-indexing content.
5. Record stale sources, obsolete assumptions, and knowledge that should be
   retired instead of refreshed.

## Expected Output

- knowledge unit inventory
- refresh schedule
- recall check plan
- stale source warnings
- retirement or update recommendations

## Verifier Expectations

- source reference check
- review interval check
- recall checkpoint check
- stale knowledge check

## Failure Handling

If source provenance or learning objectives are unclear, propose a conservative
short-term review plan and mark long-term scheduling as unresolved.
