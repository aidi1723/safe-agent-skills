# code-refactor

**Status**: Trusted  
**Capability**: code.refactor

## Purpose

Refactor code to improve readability, maintainability, and code quality while preserving existing behavior.

## When to Use

- User requests to refactor, clean up, or improve code structure
- Code needs simplification without changing functionality
- Improving naming, organization, or patterns

## What This Skill Does

- Analyzes code structure and identifies refactoring opportunities
- Applies refactoring patterns (extract method, rename, simplify conditionals)
- Preserves existing behavior and test coverage
