# Media Agentic Video Pipeline Plan

## When To Use

Use this skill when a video request needs more than a script or shot list:
reference video analysis, pipeline selection, tool/provider choice, cost
estimation, asset rights, render readiness, or post-render QA.

This skill provides method and review boundaries only. It does not run media
generators, renderers, downloads, uploads, or publishing workflows.

## Safe Workflow

1. Classify the request by output: explainer, animation, documentary montage,
   screen demo, localization, clip repurpose, talking head, or cinematic edit.
2. If a reference video is supplied, extract only allowed observations:
   transcript structure, hook, pacing, scene rhythm, keyframe intent, style
   constraints, and what must be changed.
3. Produce two or three differentiated concepts before asset generation.
4. Select a pipeline with explicit stages: research, proposal, script,
   scene plan, assets, edit, compose, review, and handoff.
5. Record the provider or local-tool route as a decision log with alternatives,
   expected cost, quality tradeoffs, latency, rights, and approval threshold.
6. Define render gates before execution: dimensions, duration, frame coverage,
   caption readability, audio levels, source rights, motion safety, and platform
   output profile.
7. Keep creative approval separate from runtime approval. Any render, media API,
   paid generation, upload, or publication action needs host approval.

## Expected Output

- reference analysis summary or original brief
- concept variants and selected direction
- pipeline and stage plan
- asset, rights, and caption inventory
- provider route and cost estimate
- pre-render and post-render QA checklist
- approval gates and unresolved risks

## Verifier Expectations

- reference-source and rights check
- cost estimate and spend-cap check
- provider route rationale check
- scene timing and caption coverage check
- audio, frame, and delivery-promise QA plan
- explicit runtime approval boundary

## Failure Handling

If source rights, budget, render tools, or platform specs are unclear, stop at
a production brief and list the missing decisions. Do not infer consent to
generate, render, publish, or spend.
