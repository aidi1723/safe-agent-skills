# Media Asset Review

## When To Use

Use this skill when a task involves reviewing generated or supplied media
assets before publication, reuse, or handoff.

## Safe Workflow

1. Identify asset type, target channel, required dimensions, and output format.
2. Check whether the asset exists and can be opened or rendered.
3. Review visual or media quality against the requested use.
4. Check rights, likeness, brand, and source-material constraints when relevant.
5. Avoid claiming usage rights when provenance is unclear.
6. Record required edits or export steps.

## Expected Output

- asset readiness status
- format and dimension notes
- quality findings
- rights or provenance risk notes
- export or edit checklist

## Verifier Expectations

- asset existence check
- format check
- render or visual inspection
- rights and source checklist

## Failure Handling

If provenance or usage rights are unclear, mark the asset as review-required
instead of publication-ready.
