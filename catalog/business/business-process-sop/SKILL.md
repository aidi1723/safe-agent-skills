# Business Process SOP

## When To Use

Use this skill when a repeated business workflow needs a clear operating guide
for people or agents.

## Safe Workflow

1. Identify trigger, owner, inputs, outputs, tools, and completion criteria.
2. Break the workflow into ordered steps with decision points.
3. Add quality checks and escalation conditions.
4. Keep permissions and approvals visible.
5. Include maintenance owner and review cadence.

## Expected Output

- SOP title and purpose
- roles and inputs
- step-by-step process
- quality checks
- escalation path

## Verifier Expectations

- role clarity check
- step order check
- approval and handoff check
- completion criteria check

## Failure Handling

If a process has multiple variants, write the default path first and list
variants separately.
