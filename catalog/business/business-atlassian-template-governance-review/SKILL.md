# Business Atlassian Template Governance Review

## When To Use

Use this skill when teams need to review Jira, Confluence, or Atlassian
templates before rolling them out across projects or departments.

## Safe Workflow

1. Identify template purpose, audience, owner, lifecycle, required fields, and
   systems where it will be used.
2. Separate required content, optional guidance, workflow gates, naming rules,
   permissions, and reporting dependencies.
3. Check whether templates create clear evidence, reduce ambiguity, and avoid
   duplicating existing approved templates.
4. Flag missing ownership, stale fields, sensitive data prompts, and governance
   conflicts.
5. Produce a template readiness review, not a forced rollout plan.

## Expected Output

- template scope summary
- field and workflow findings
- duplication and governance risks
- permission and sensitivity notes
- rollout readiness checklist

## Verifier Expectations

- owner and audience check
- required field check
- duplicate template check
- sensitive data prompt check

## Failure Handling

If template ownership or target workflow is unclear, recommend a pilot and
approval checkpoint before broad rollout.
