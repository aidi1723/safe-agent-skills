# Business Sales Engineering Review

## When To Use

Use this skill when a pre-sales, solutions, product, or delivery team needs to
review technical fit, demo scope, implementation risk, or handoff readiness.

## Safe Workflow

1. Identify prospect context, use case, required capabilities, constraints,
   buyer criteria, and handoff owner.
2. Separate confirmed requirements, assumptions, technical gaps, integration
   needs, data dependencies, security questions, and demo promises.
3. Check whether claims map to available product capability or approved roadmap
   commitments.
4. Flag implementation, security, support, and commercial risks before proposal
   or handoff.
5. Produce a fit and readiness review with validation steps.

## Expected Output

- discovery and fit summary
- capability-to-requirement map
- assumption and gap register
- demo and proof plan risks
- delivery handoff checklist

## Verifier Expectations

- requirement evidence check
- capability claim check
- integration and security check
- handoff owner check

## Failure Handling

If technical fit is uncertain, recommend validation steps before commercial
commitment.
