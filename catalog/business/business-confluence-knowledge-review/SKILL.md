# Business Confluence Knowledge Review

## When To Use

Use this skill when a team needs to review Confluence spaces, page structure,
knowledge ownership, decision records, stale content, or wiki governance.

## Safe Workflow

1. Identify audience, spaces, page hierarchy, owners, permissions, and freshness
   expectations.
2. Separate official policy, project notes, decision records, SOPs, drafts, and
   archived content.
3. Check ownership, duplication, broken links, stale pages, missing source
   context, and access boundaries.
4. Recommend structure and maintenance routines before tool or permission
   changes.
5. Produce a prioritized cleanup plan with verification criteria.

## Expected Output

- Confluence inventory summary
- stale and duplicate content findings
- ownership and permission risks
- IA recommendations
- cleanup backlog

## Verifier Expectations

- owner and permission check
- freshness check
- link and duplicate check
- source authority check

## Failure Handling

If space inventory is incomplete, use a sampling plan and mark coverage limits.
