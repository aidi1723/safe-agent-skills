# Business Atlassian Admin Governance Review

## When To Use

Use this skill when a team needs to review Jira, Confluence, or broader
Atlassian administration choices for governance, permissions, and operating
risk.

## Safe Workflow

1. Identify workspace, product, project, owner, administrator, permission
   model, and affected teams.
2. Separate user access, project roles, workflow settings, automation rules,
   data retention, integrations, and audit logging.
3. Check whether permission changes, global settings, automations, or workflow
   edits have owner approval and rollback notes.
4. Flag security, compliance, data exposure, and operational continuity risks
   before changes are made.
5. Produce a governance review; do not execute admin changes or grant access.

## Expected Output

- administration scope summary
- permission and role findings
- automation and workflow risks
- approval and rollback gaps
- governance checklist

## Verifier Expectations

- owner and authority check
- permission boundary check
- automation side-effect check
- audit and rollback check

## Failure Handling

If current configuration evidence is missing, mark findings as draft and list
the exact admin exports or screenshots needed for review.
