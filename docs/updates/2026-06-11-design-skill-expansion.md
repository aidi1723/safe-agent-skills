# Design Skill Expansion

## Summary

Added three trusted design skills for product-grade frontend work:

- `design-tailwind-radix-system` for Tailwind CSS, Radix UI, and shadcn/ui-style component systems.
- `design-motion-interaction-polish` for accessible UI micro-interactions, CSS animation, Motion for React, and reduced-motion checks.
- `design-premium-landing-page` for premium landing pages, Awwwards-style reference boundaries, conversion hierarchy, and template-drift removal.

## Safety Decision

- The new skills are advisory workflow guidance only; they do not grant shell, network, browser, package installation, or production permissions.
- Awwwards, Godly, Lapa Ninja, Cruip, Magic UI, and Aceternity UI are treated as pattern references, not copy sources.
- `front end design` and `creative aesthetics` were not added as standalone skills because their useful checks are covered by `design-ui-review`, `$design-md-ui`, and the new focused design skills.
- The website launch bundle keeps release checks ahead of optional premium design skills so bounded task packs still include `execution-publish-check`.

## Catalog Changes

- Catalog count increased from 106 to 109 sanitized skills.
- Trusted skill count increased from 100 to 103.
- `website-build-launch` now includes optional Tailwind/Radix, premium landing, and motion polish capabilities.
- `ui-quality-review` overlap metadata now includes the new design skills as adjacent targeted checks.
