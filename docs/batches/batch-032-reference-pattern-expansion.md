# Batch 032 Reference Pattern Expansion

This batch adds trusted local skills inspired by five external reference
projects without importing their runtime code, prompt bodies, connectors, or
execution behavior.

- Agent-Reach informs `research-multi-platform-search-boundary`: multi-platform
  public-source discovery planning, account/session boundaries, citation
  requirements, and anti-scraping permission gates.
- ai-berkshire informs `business-value-investment-research-framework`:
  evidence-backed investment research, opposing views, valuation assumptions,
  and financial-advice boundaries.
- agency-agents informs `ai-agent-role-library-governance`: reusable role
  library governance, handoff contracts, role conflict checks, and output
  ownership for multi-agent teams.
- Google DESIGN.md ecosystem references inform
  `design-design-md-system-contract`: DESIGN.md source-of-truth checks, token
  and component state coverage, implementation mapping, and accessibility
  review.
- SimpleX Chat informs `compliance-private-communication-boundary`:
  identifier minimization, metadata review, end-to-end encryption boundaries,
  and privacy threat-model questions for communication workflows.

OpenMontage and codebase-memory-mcp were reviewed again and remain covered by
batch 031 skills. This batch does not duplicate those capabilities.

All entries are OneCode-authored method skills under Apache-2.0. The external
projects remain reference sources only.
